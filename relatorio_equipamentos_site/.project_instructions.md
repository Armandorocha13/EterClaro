# Relatório de Instalações de Equipamentos

## Overview
Dashboard for analyzing equipment (terminal) installation data from Excel files. Technicians install terminals and the system projects material replenishment needs.

## Key Business Logic
- **FIXED 7 days worked** for ALL technicians (never calculated from data)
- Média diária = quantidade total / 7
- Projeção 7 dias = Math.ceil(média diária × 7) = effectively the total installed (rounded up)
- Volume badges: Alto (≥50), Médio (≥20), Baixo (<20)

## Technical Stack
- Next.js 14 with App Router
- PostgreSQL via Prisma (Upload + Installation models)
- xlsx library for Excel parsing
- Recharts for data visualization
- HTML2PDF API for PDF export
- Cloud storage (S3) configured but Excel is processed server-side directly

## Excel Structure
Required columns: TÉCNICO, DESCRICAO, SERIAL, DATA (auto-detected, case-insensitive)

## Visual Style
- Blue gradient header (#1a73e8 to #4285f4)
- White cards with subtle shadows on light background
- Corporate blue/green/amber accents
- All text in Portuguese (pt-BR)
- Font: DM Sans (body), Plus Jakarta Sans (headings), JetBrains Mono (numbers)

## Pages & Routes
- `/` - Home: Upload zone or Dashboard (based on data availability)
- `/api/upload` - POST: Excel file upload and parsing
- `/api/data` - GET: Processed data with filters
- `/api/generate-pdf` - POST: PDF generation from HTML

## Data Flow
1. User uploads Excel → parsed server-side → stored in PostgreSQL
2. Dashboard loads data from API → processes client-side for filters
3. Filters: by técnico, modelo, text search (all real-time)
4. PDF export generates HTML table report via Abacus AI HTML2PDF API
